# 📊 Investor Behaviour Analytics Dashboard

## 📝 Overview
This project is a Power BI dashboard designed to analyze investor demographics, preferences, and behavior patterns.  
It provides actionable insights into how different genders approach savings, investment objectives, and information sources.

## 🔑 Features
- **Demographics Overview**: Gender distribution, average age, and investment duration
- **Saving Objectives by Gender**: Education, healthcare, retirement planning
- **Investment Objectives Distribution**: Capital appreciation, growth, and income
- **Monitoring Habits**: Mutual funds, equities, fixed deposits, provident funds
- **Investment Preferences by Gender**: Equity markets, government bonds, mutual funds
- **Information Sources**: Consultants, media, and digital platforms

## 📈 Key Insights
- Male investors show stronger interest in retirement planning
- Capital appreciation is the dominant investment objective
- Mutual funds are the most closely monitored investment avenue

## 🛠️ Tech Stack
- **Power BI** for interactive dashboards and data visualization
- **Data Analytics** techniques for extracting behavioral insights

## 🚀 How to Use
1. Clone the repository  
2. Open the `.pbix` file in Power BI Desktop  
3. Explore the interactive dashboard with filters and charts
